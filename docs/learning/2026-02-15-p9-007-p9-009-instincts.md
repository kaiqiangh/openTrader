## Learned Instincts

1. Integrity audits should combine fault detection and recovery assertions.
   - Detection-only tests are insufficient without proving snapshot/resync recovery behavior.

2. Security acceptance gates are strongest when they span both application and infra boundaries.
   - RBAC-only checks miss compose exposure and secret validation regressions.

3. Release readiness should be enforced by documentation contract tests.
   - Checklist/runbook existence and plan status checks prevent “done in code, missing in ops docs” drift.

4. Final-phase closure works best with explicit go/no-go and rollback ownership.
   - Operational ambiguity is a larger risk than missing minor technical polish near release.
