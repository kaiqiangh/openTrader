# Continuous Learning - P9 Replay, Performance, and Resilience (2026-02-15)

## Session Context

- Implemented and validated `P9-004`, `P9-005`, and `P9-006` with deterministic replay tests, performance benchmark harnesses, and chaos fault-injection drills.

## Learned Instincts

1. Replay determinism must validate both digest stability and chain reproduction.
   - Digest-only checks can miss lifecycle mismatch regressions.
   - Replay suites should assert stored lifecycle event ordering explicitly.

2. Performance gates in CI should use bounded thresholds and deterministic in-memory harnesses.
   - Tight absolute latency budgets are environment-sensitive and create flaky gates.
   - Relative/upper-bound checks plus benchmark evidence docs are more stable.

3. Chaos validation is most maintainable when drills map directly to existing domain modules.
   - Broker, exchange, LLM, and persistence failure modes can be exercised with small fault-injection doubles.
   - This avoids introducing heavy orchestration dependencies for every validation run.

4. Documentation contract tests prevent plan drift during fast phase transitions.
   - Enforcing artifact existence and next-task pointers keeps implementation and planning synchronized.
