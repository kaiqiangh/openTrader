# P3-001 P3-002 P3-003 Agent Runtime Baseline Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver the Phase 3 baseline by adding an orchestrator skeleton that consumes canonical market envelopes, plus planner and risk agents that produce deterministic decision and risk outputs.

**Architecture:** Introduce an `agent_orchestrator` package with explicit contracts and small pure-Python modules. `AgentOrchestrator` will validate inbound market envelopes, invoke `PlannerAgent` and `RiskAgent`, and publish lifecycle events plus execution intents via an abstract publisher. Planner and risk logic remains deterministic and rule-based for now so later LLM gateway integration can be layered without changing orchestration contracts.

**Tech Stack:** Python 3.13+, pytest, dataclasses, async protocols, existing shared message envelope validator.
