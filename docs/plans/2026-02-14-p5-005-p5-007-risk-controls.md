# Phase 5 Risk Controls Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver `P5-005`, `P5-006`, and `P5-007` with deterministic OMS-side risk enforcement and emergency stop controls.

**Architecture:** Add composable OMS risk modules: core position/exposure/leverage rules, portfolio-level drawdown/daily-loss guards, and a circuit-breaker/kill-switch control layer. Then compose them behind a single risk-policy evaluator that returns explicit allow/deny decisions and rule-level outcomes for downstream observability.

**Tech Stack:** Python 3.13, dataclasses, pytest, ruff.
